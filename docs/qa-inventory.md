# Verification inventory

Version 0.1.0 is uncalibrated research software. Passing these checks verifies specified software behavior, not biological truth.

## Numerical and scientific checks

The automated suite covers zero-primary/secondary/target/release/internalization controls, untreated receptor steady state, nonnegativity tolerance, primary and secondary amount conservation, cell-state conservation, all four addition orders, exact zero-delay equivalence, endpoint-only delayed dosing, reporter accumulation, reporter-loss separation from killing, monotonic saturation, input validation, solver tolerance, accelerated/reference RHS parity, the analytic equilibrium maximum, and the high-primary asymptote.

`tools/verify_atlas.py` checks every atlas row's dimensions and numeric validity and independently recomputes nine representative dose conditions from the Python model. Additional mechanism-lab consistency is checked by the same script. The complete data remain synthetic and uncalibrated.

`results/sensitivity.json` retains both favorable and unfavorable spatial-resolution tests. The transport stress case is explicitly not mesh-converged. Parameter uncertainty is explored through discrete scenarios, not statistical confidence intervals or an inferred posterior.

## Browser checks

The public explorer should load without installation; expose both atlas and mechanism-lab modes; update all selectors and paired plots; distinguish molecule-count readouts from normalized responses; export usable CSV, parameter JSON, and chart PNG; expose exact-value tables; handle data-loading errors; support light/dark mode and keyboard focus; and fit desktop/mobile widths without horizontal page overflow.

The browser does not solve a second, approximate model. It displays the JSON generated by the Python implementation and labels connection lines as visual guides.

## Publication checks

Before release: run the test suite; recompute reference rows; inspect figures; test browser downloads and state transitions; validate citation metadata and the MIT license; screen public text for private context; confirm Pages resolves; and check the remote CI run. Record any check that cannot be completed rather than implying it passed.
